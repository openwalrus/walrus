# berm-fixture

Both ends of a nested call in one image: `nest` reaches another harness by name,
`echo` and `boom` are what a name can resolve to. One ELF deployed under several
names drives every outcome `berm.call` carries — the payload arriving, a target
that ran and said no, and a name nothing answers for.

```sh
cargo build --release -p berm-fixture --target riscv64imac-unknown-none-elf
cargo run --example call -p crabtalk-berm
```

Not installed by `make harness`, and nothing in a running daemon declares it.
